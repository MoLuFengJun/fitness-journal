## 一轮执行方式

1. 读 AGENTS.md 和 [STATUS](progress/STATUS.md)。
2. 在 [路线图](DEVELOPMENT-PLAN.md) 找到首个依赖满足的任务。
3. 只打开该任务卡及其中引用的规格。
4. 执行 → 验证 → 更新状态/会话记录 → 按授权提交同步。
5. 下次会话从 STATUS 继续，不凭聊天记忆判断进度。

如果 STATUS 与仓库代码冲突，先核实代码和测试，修正状态，保留更正原因。未经验证不能将 TODO 改为 DONE。

## 遇到问题

- 缺少工具：执行 SETUP-WINDOWS 对应步骤，不直接下载来源不明压缩包。
- SDK/Gradle 不匹配：对照已锁定版本和官方兼容说明，只改必要项。
- 设备未连接：可进行纯逻辑工作，保留 NEEDS_DEVICE_CHECK，不能跳过发布真机门槛。
- 需要审美判断：展示具体画面并记录待反馈；可继续独立的数据/计算工作。
- 发现新需求：写进 DECISIONS 的待定区，不偷偷加入当前任务。
- 权限或网络阻塞：记录具体命令和错误，说明用户需要执行哪一步；不假称成功。
