- 环境未知：远程只读或独立文档可继续，本机操作先确认。

- 缺设备：继续可独立验证的工作，保留NEEDS_DEVICE_CHECK。
- 缺视觉反馈：展示具体结果并保留待反馈状态。
- 状态与代码不一致：先核验证据，不能凭旧聊天断言完成。
