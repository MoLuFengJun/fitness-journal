# 会话记录模板

文件名：docs/sessions/YYYY-MM-DD-Txx.md；同日多轮可加短后缀。

- 日期与时区：
- 任务ID：
- 开始分支与提交：
- 目标：
- 读取的规格：
- 实际修改：
- 未改变/明确推迟的边界（仅必要项）：
- 验证命令或人工步骤：
- 实际结果：PASS / FAIL / NOT_RUN：
- 截图或报告（仅虚构数据）：
- 发现的问题与处理：
- 仍需真机/用户反馈：
- 结束任务状态：
- 下一任务与第一步：
- 本地提交：
- 是否已推送及远程核验结果：

不得填写真实体重、药名、食物日记、设备序列号或密钥。
未运行写NOT_RUN，不使用“应该没问题”代替结果。
