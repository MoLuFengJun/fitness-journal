# 会话记录模板

文件名：docs/sessions/YYYY-MM-DD-Txx-ENV.md；文档维护可使用描述性后缀。
公开记录仅用脱敏信息，不包含机器名、代理地址、私人路径、密钥或真实健康数据。

- 日期与时区：
- 环境ID：COMPANY / HOME / UNKNOWN（仅远程独立文档可UNKNOWN）
- 识别依据：用户本轮确认 / 匹配本机标记 / 待询问
- 本轮是项目任务还是本机环境补齐：
- 项目任务ID / 环境检查ID：
- 本地是否有可用checkout：
- 开始远程分支/基线SHA：
- 本地开始分支/SHA（无则写无）：
- 目标与读取规格：
- 实际修改：
- 验证环境、命令/操作、所测提交：
- 结果：PASS / FAIL / NOT_RUN；证据：
- 仍待真机/本机/视觉反馈：
- 网络通道：普通Git / GitHub连接器 / 未同步
- 失败通道及脱敏错误类别：
- 是否有条件变化允许重测：
- 本地提交SHA（如有）：
- 已核验远程分支/SHA：
- local/remote是否同SHA（API通常不是同一本地提交）：
- 已同步路径 / 未同步工作：
- 本地副本是否已对齐远程：
- 下一台电脑应读取的分支及第一步：
- STATUS和对应环境档案是否更新：
- 结束状态与下一任务：

不把连接器写入成功记为git push成功；不把别的机器PASS冒充本机PASS。
同一提交正文不能填写尚未生成的自身SHA，用随后交接或Git历史定位。
