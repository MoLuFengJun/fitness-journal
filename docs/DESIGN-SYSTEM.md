# 视觉与交互规范 v0.1

## 用户确定的视觉方向

晴川蓝 #79BEDF 为主调，缃云黄 #F4DC84 为另一端。
重点是颜色过渡和冷暖对照，而不是给两张卡片各填一个纯色。
界面轻盈、清爽、温暖；重要数值突出，训练录入紧凑好按。

## 设计令牌（辅助色为实施初稿）

| token | 初始值 | 用途 |
| --- | --- | --- |
| BrandBlue | #79BEDF | 渐变起点 |
| BrandYellow | #F4DC84 | 渐变终点 |
| Background | #F7FAFC | 页面底 |
| Surface | #FFFFFF | 普通卡片 |
| TextPrimary | #203540 | 正文和大数字 |
| TextSecondary | #52636B | 次要信息，仍须测对比度 |
| Divider | #E2E8EC | 分隔线 |
| Error | #A73535 | 错误文字，结合图标/说明 |

主渐变：蓝在左上、黄在右下，先用两个端点实现；若中段发灰，可尝试一个更明亮的过渡点，但需截图比较，不擅自改用户指定端点。
主卡片、进度环、完成反馈使用渐变；日记列表和输入框保持干净中性底色。
不让每张卡片都渐变；不使用持续流动背景，避免训练时分散注意。
第一版固定明亮主题；不启用壁纸动态取色，后续深色主题单独设计。

## 版式

- 手机竖屏优先，横屏至少能正常滚动且不遮挡。
- 4dp 基础网格；常用间距 8/12/16/24dp，页面侧边距起点16dp。
- 卡片圆角起点20dp，输入区域12dp；不是所有组件都做大胶囊。
- 主要数值约28–36sp，标题20–24sp，正文16sp，辅助13–14sp。
- 使用系统中文字体，不为字体增加付费或远程下载。
- 数字尽量使用等宽数字特性，重量和次数列对齐。
- 内容避让状态栏、导航栏与键盘；不靠写死屏幕高度排版。

## 三页布局初稿

总览：顶部日期与设置 → 今日主卡（能量/蛋白）→ 体重快捷记录 → 训练/提醒摘要 → 周期切换与趋势。
吃：日期 → 营养目标/已记录 → 常用食物快捷区 → 分餐列表 → 固定清晰的添加入口。
练：当前训练/开始入口 → 动作卡（上次参考）→ 大号重量/次数输入与完成按钮 → 历史入口。
底部导航始终只有总览/吃/练；设置不新增为第四个主 Tab。

## 关键组件

- EnergyCard：渐变底、深色文字、目标/已记录/剩余三项；未完整记录时有状态说明。
- NutritionProgress：克数优先，比例为辅助；超过目标仍显示真实值。
- SetRow：组号、重量、次数、完成按钮；大点击目标；撤销完成可用。
- PreviousPerformance：同器械同口径最近完成训练；上次数据只作参考，不自动当作今天完成。
- QuickFoodChip：名称与一份单位；点后可调份数，不要求重新填营养值。
- EmptyState / ErrorState：告诉用户能做的下一步；不要使用虚构样本冒充真实数据。
- ChartSummary：曲线旁提供数值摘要和列表，不能只靠颜色表达。

## 动效与可访问性

- 普通交互动画初始180–250ms，减少运动系统设置下尊重系统动画缩放。
- 点击范围至少48dp；训练完成按钮不贴边。
- 常规文字对比度目标至少4.5:1，大字/关键图形至少3:1；必须实测，品牌色不能直接做浅底小字。
- 图表线条可用更深的蓝作数据线，浅黄用填充/点缀；数值标签和线型辅助区分。
- 支持字体放大至200%，至少主要任务不丢失操作。
- 图标提供正确语义；装饰图不重复朗读。
- 色彩不是唯一状态信号：完成有勾选，错误有文字。

## 视觉验收

T04–T06 使用明确标记的虚构数据生成 Compose Preview 和运行截图。
至少检查360dp及较窄宽度、长中文、无数据、超目标、键盘展开、字体放大。
展示同一内容的渐变主卡和整页效果；未获用户反馈记为“视觉待反馈”。
不需要先购买设计工具；直接使用 Compose 原型，不另外建设 Web 项目。
