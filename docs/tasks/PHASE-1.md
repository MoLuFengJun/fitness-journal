# 阶段1：先把视觉与录入方式做对

## T04 设计令牌和基础组件

输入：DESIGN-SYSTEM、PRODUCT、已构建模板。
操作：
1. 创建ui/theme的颜色、间距、字型、形状，关闭壁纸动态取色。
2. 实现蓝黄渐变主卡、普通卡、数值标题、按钮、空状态组件。
3. 组件预览使用虚构数值和清晰标签。
4. 实测文本与背景对比度；浅品牌色不直接做小字。
产出：可复用组件及Preview。
验收：assembleDebug/lint；运行截图中端点色正确，主卡深色文字清楚。
边界：不引入付费组件，不做无限动效、深色主题、网络字体。
下一项：T05。

## T05 三个页面与导航原型

输入：PRODUCT页面定义、DESIGN-SYSTEM。
操作：
1. 添加总览、吃、练三个主入口与设置入口。
2. 用专用Preview/Fake数据源展示空状态和有数据状态，明确虚构。
3. 实现日期切换、添加入口、训练组输入的布局，暂不伪装已持久化。
4. 页面滚动、返回、底部导航状态处理好。
5. 不把食物库、动作库、设置扩展成额外主Tab。
产出：三个可以实际切换的页面。
验收：主要入口可点击；无登录；小屏/键盘不挡主操作；基础导航UI测试。
边界：Fake数据只存在debug/demo路径，后面生产版本必须移除。
下一项：T06。

## T06 关键录入原型与视觉检查

输入：T05、DESIGN-SYSTEM、TEST-PLAN E05。
操作：
1. 做体重输入、食物份量、训练重量/次数三种表单。
2. 处理空输入、小数、保存/取消、错误提示和键盘Next/Done。
3. 跑无数据、长中文、360dp/窄屏、字号放大场景。
4. 展示三页具体截图供用户纠正审美，记录反馈而非自行声称认可。
5. 将确认修改写回DESIGN-SYSTEM；尚未反馈保留标记。
产出：可实现的交互与截图检查记录。
验收：三种录入无需多余跳转；保存/取消可区分；控件可点击可阅读。
停止：视觉待反馈可继续T07，不再增加新的视觉方向。
下一项：T07。
