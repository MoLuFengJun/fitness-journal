# 阶段4：练

## T15 动作、器械口径与模板

输入：PRODUCT、ExerciseDefinition/WorkoutTemplate、C05。
操作：
1. 实现自定义动作，名称、器械、负重类型和计重方式明确。
2. 负重类型至少区分外部负重、助力、自重；自重无额外负重时允许空负重。
3. 单只哑铃、两只总重、器械显示值分别标注，不自动换算成同一个成绩。
4. 实现简单动作列表模板，参考组数可编辑。
5. 改变比较口径要新建定义/版本，不能把已有历史混在一起。
产出：动作库、模板选择与编辑。
验收：同名不同器械可独立存在；助力有清楚提示；归档不破坏训练历史。
下一项：T16。

## T16 每组记录与训练草稿

输入：WorkoutSession/WorkoutExercise/WorkoutSet、PRODUCT。
操作：
1. 开始训练创建DRAFT，再选动作/模板。
2. 预填上次参考重量次数，但completedAt必须为空。
3. 每组可修改、完成、撤销完成、添加或删除；RIR为可选。
4. 有效输入及时落盘，未输入完的小数先留编辑状态，不写入非法值。
5. 退后台/进程终止后恢复草稿；离开页面不能丢已保存组。
6. 结束训练处理未完成组，保留其未完成状态且不纳入成绩。
7. 防止连续点击开始/结束生成重复session。
产出：健身房可实际使用的训练记录流程。
验收：两组完成一组未完成的计数正确；复制不复制完成；重启恢复；事务测试。
下一项：T17。

## T17 上次、最好表现与能耗

输入：C04/C05，训练数据。
操作：
1. 展示同条件上次完成训练的各组。
2. 实现同重量次数纪录、同次数重量纪录；不可排序组合保留多个。
3. 助力比较方向反转；不同器械与计重方式不混比。
4. 能耗作为可选模块：输入明确时长与活动类型，使用有来源MET粗估。
5. 显示“粗估/包含该时段静息消耗”，不从吨位推导。
6. 同一session能耗只记一份；不把它重复加到包含训练的维持消耗。
产出：训练页参考与历史趋势所需查询。
验收：V08/V10/V13/V14；未完成组/热身不进入主要纪录；无时长可不估算。
边界：不做自动加重处方，不把纪录提升直接称为肌肉增长。
下一项：T18。
