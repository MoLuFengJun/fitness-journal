# 文件备份与恢复 v1

## 范围

第一版是手动导出/导入完整快照。网盘、WebDAV、自动云上传与多设备合并均未决定。
“文件已写出”不等于“已保存到远程”；界面不得显示虚假的已同步状态。
文件格式要能被未来鸿蒙端独立解析，不直接复制正在运行的 SQLite 文件及 WAL。

## 格式

UTF-8 JSON，扩展名 .fjbackup；MIME 使用 application/json。
根对象示意（空数组仅用于结构说明，不是测试完成证明）：

~~~json
{
  "format": "fitness-journal",
  "schemaVersion": 1,
  "exportedAt": "2026-11-02T00:00:00Z",
  "appVersion": "0.1.0",
  "payload": {
    "profile": null,
    "preferences": null,
    "bodyMeasurements": [],
    "goalPeriods": [],
    "foods": [],
    "mealTemplates": [],
    "mealTemplateItems": [],
    "foodEntries": [],
    "dayLogStates": [],
    "exercises": [],
    "workoutTemplates": [],
    "workoutTemplateItems": [],
    "workoutSessions": [],
    "workoutExercises": [],
    "workoutSets": [],
    "activities": [],
    "reminderSchedules": [],
    "reminderOccurrences": []
  }
}
~~~

- 字段使用稳定英文名，单位通过字段名固定（weightG、proteinMg、energyKcalMilli等）。
- UUID/日期/枚举有文档定义；所有必填集合必须存在，缺失不能直接当空集合覆盖本机。
- 记录计数在预览时计算，不能盲信文件内声明。
- 设备路径、通知权限、签名、日志、备份事件不导出。
- v1 是明文文件，导出页明确包含个人数据；不能在宣传中写加密。
- 远程传输方案决定后，再评估使用成熟库/平台API的加密封装和独立恢复密钥；禁止自行发明密码算法。

## 导出流程

1. 通过一个数据库事务获得所有实体的一致快照。
2. 序列化到应用私有临时文件，验证可被自身解析、数量与关系完整。
3. 通过系统 ACTION_CREATE_DOCUMENT 让用户选择输出位置。
4. 完整写入并关闭 stream 成功后才记录“导出成功”。
5. 取消、空间不足、写入失败：保留原数据库，不更新成功时间；说明可重试。
6. 清理本次临时文件，不删除用户其他文件；部分外部文件写入失败要提示，后续导入必须能拒绝残缺文件。
7. 文件名使用时间戳，避免无提示覆盖上一份。

不为导出申请所有文件访问权限。

## 导入流程：只支持替换

1. 用户选文件；在读取流时限制总字节数（初版20MiB，可配置），不能先读无限文件再检查。
2. 解析到独立 DTO；严格检查 format、schemaVersion、字段类型、有限数、合法枚举、日期、UUID、重复ID和外键。
3. 校验所有约束；比本版本更新的格式明确拒绝，不静默丢字段。
4. 展示文件日期、各实体数量、当前本机数量，以及“将替换本机记录”。
5. 用户确认替换前提供导出当前数据的入口；未确认不修改任何本机数据。
6. 一个 Room 事务内按依赖顺序删除/插入；任一步失败完整回滚。
7. 成功后刷新所有页面；取消旧待触发提醒，根据恢复设置进入“待重新检查权限/启用”状态，不立即补发过去通知。
8. 校验失败、取消、事务失败时本机数据完全不变。
9. v1 不做增量合并；不要因为重复导入而叠加两遍数据。

## 兼容性

Room DB版本与备份schemaVersion独立。
未来schemaVersion2必须有v1→v2转换测试；不能用“只支持最新文件”代替已承诺的升级兼容。
保留无个人数据的 golden fixture 到 app/src/test/resources/backup/，它是迁移的长期合同。
旧文件升级后历史日期/营养快照/训练口径保持。

## 必测案例

- 包含每种实体的完整虚构快照往返，字段与ID一致。
- 中文、emoji、空可选字段、跨日、助力动作、归档食物、训练草稿。
- 空数据文件可恢复为空，但必须明确预览和确认。
- 残缺JSON、超大文件、未知版本、重复ID、孤儿关系、非法单位/数值：拒绝且不改本机。
- 导出中断、用户取消、导入事务注入失败：不能丢本机数据。
- 相同文件两次替换结果一致。
